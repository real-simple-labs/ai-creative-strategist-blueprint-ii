# AI Creative Strategist Blueprint II

The public course archive for Parker's six-week **AI Creative Strategist Blueprint II** course, taught in August–October 2026.

This repository brings the course into one durable place:

- every main, Q&A, office-hours, and guest-session recording that has been posted;
- verbatim transcripts for all six main sessions, the September 1 office hours, and all four guest sessions;
- first-party slide decks, guest materials, and course images that were posted to the live hub;
- stable links to each learner-facing week page, slide deck, prompt, and supporting resource.

The live [Course Home](https://realsimplelabs.notion.site/AI-Creative-Strategist-Blueprint-II-Course-Home-3ad120b5a80081aaab8defd8e900460f) remains the source of truth for learner-facing materials. This repository is the durable session archive.

## The course operating model

The six weeks build one system:

1. Use Claude Code or Codex as a working harness, not only a chat window.
2. Turn proven recurring work into skills.
3. Store domain expertise, tribal knowledge, and interpreted data in a shared Brain.
4. Connect live tools and evidence through MCPs.
5. Keep humans at consequential creative, communication, publishing, and spend gates.
6. Feed outcomes and corrections back into the system so the next run starts smarter.

## Archive rules

- Preserve transcript bodies verbatim.
- Preserve correction notes only in public archive headers; do not add internal analysis or operating commentary.
- Keep original recording and resource URLs intact.
- Keep raw `.vtt` files when that is the source supplied for a session.
- Store first-party course decks and images under `resources/`; keep recordings on YouTube rather than in Git.
- Do not store skills, scripts, swipe libraries, or reusable Parker Brain prompt systems in this repository.
- The learner-facing Notion Course Home remains authoritative for newly posted files and recordings.
