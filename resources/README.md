# Course resources

This directory preserves first-party teaching assets from the live Notion Course Home.

- `slides/` contains exported course and guest-session decks.
- `images/` contains images and diagrams posted as course resources.
- Recording files are intentionally not stored in Git. The repository links to their YouTube copies instead.
- Skills, scripts, swipe libraries, reusable prompt systems, and other Parker Brain machinery are intentionally excluded. Those belong in the Parker Brain repository.

The live [Course Home](https://realsimplelabs.notion.site/AI-Creative-Strategist-Blueprint-II-Course-Home-3ad120b5a80081aaab8defd8e900460f) remains the source of truth for newly posted materials.
