## Installation prompt

Replace the bracketed operating system before using this prompt:

> I need to install Git so Claude Code can run on my computer. I am on a [Mac or PC]. Walk me through it step by step and assume I have never opened the terminal, know what a terminal is, installed Homebrew, or anything. Do not show all the steps at once. Go one by one and make sure I finish each step before telling me the next one.

## Readiness checklist

- [ ] Claude Code is installed and opens on my computer.
- [ ] I watched all four videos in order.
- [ ] I can explain the difference between Claude Chat and Claude Code.
- [ ] I know GitHub is where a project's files and change history can live online.
- [ ] I know an MCP connects Claude to another tool or source of information.

If setup differs from the recording, stop at that step, take a screenshot, preserve the complete error message, and ask Claude or ChatGPT to diagnose it before continuing.
